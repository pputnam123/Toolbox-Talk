QR Access — the one posted code

This file gets hosted at one web address. The permanent QR code encodes only that address, plus #today so a scan opens straight on the talk due that day. Print it once and post it — when talks or the schedule change, you overwrite the hosted file at the same address and the printed code keeps working.

1. Host this file, then paste its address

The host must serve the file as a web page. File-share links from Google Drive, OneDrive, or SharePoint open a preview or sign-in page instead of running the file, so they are refused here.

Keeping the code working

  1. Make your changes here — talks, schedule, settings.
  2. In Settings, use Download this file. Your talks, schedule, and settings are baked into the downloaded copy.
  3. Upload that copy over the old file at the same hosted address.
  4. Scan the posted code once to confirm the new talk shows. The code itself never changes.
